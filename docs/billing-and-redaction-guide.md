# 计费与敏感信息替换配置

本指南适用于 home 的 jjdguard-gateway 虚拟机。

## 时段计费

进入“资源与计费 → 计费中心 → 模型时段计费”。选择工作日峰谷、夜间优惠、周末优惠、全天标准或自定义模板后，可批量添加模型、复制方案并修改时间与倍率。跨午夜拆为两个时间段；时间区间左闭右开。节假日日期例外覆盖周规则，按实际放假日期维护。

草稿直接编辑。已发布方案点击编辑生成下一版本草稿，发布后取代当前版本；已有账单保存原版本、命中规则和倍率。只保存不会改变当前正在使用的方案。

## 模型定价

进入“模型定价”，点击模型的“配置”。通过分组页签设置 Token、图片、工具费用。New API 仅用作计费设计和默认工具费率参考，不同步覆盖现有报价。详细说明见 [模型计费配置与 New API 参考](operations/newapi-billing-sync.md)。

生图明确选择多模态 Token 或按尺寸、质量、张数收费；结构模板只填规格，不填价格。按张模式未配置的规格会在调用前拒绝。工具通过中文目录选择，按上游实际执行计数收费，可显式采用同币种参考价。旧配置不自动迁移。

## 员工月额度

进入“员工月额度”，选择币种、时区并启用默认额度，快捷设置 100、500、1000 或自定义金额。默认规则适用于现有和新加入员工。个人/批量设置可覆盖默认；恢复默认表示继承租户规则，个人额度 0 表示禁止计费调用。

每个请求在上游调用前预占额度，结算后使用实际费用替换预占。用完拒绝后续调用；每月 1 日按配置时区进入新账期，不结转剩余额度，保留历史账单。额度服务或定价不可用时，已启用额度的员工不能绕过检查。

额度必须在计费 metering 或 prepaid 模式下启用；计费关闭时不强制执行。单次实际工具/生成用量可能超过预估，结算后阻止后续调用。控制面仅在用户配置了员工金额额度或生效的组织、部门、个人金额预算策略时，下发按可用金额折算的输出 token 上限；仅有钱包余额不触发下发，折算值超过 1,000,000 时也不下发。旧的全局“预算断流”开关已移除，默认钱包准入校验继续生效。网关对预算上限采用“只收紧、不注入”：仅在客户端已设置输出上限且大于预算 cap 时收紧（Chat Completions 的 max_tokens / max_completion_tokens、Responses 的 max_output_tokens、Messages 的 max_tokens），不把钱包折算值写入缺省请求。客户端未设置时保留供应商默认行为；Chat→Anthropic 转换默认使用 4096，再按模型上限钳制。上游遵守收紧后的上限时，返回权威用量（finish_reason=length / status=incomplete / stop_reason=max_tokens），按上游用量结算。流式与非流式都适用。个别上游不遵守输出上限时，网关停止向客户端转发并发出同样的合法结束事件，继续读取上游直到拿到权威用量再结算；拿不到时该请求转为待核对，不按估算入账。未下发预算 cap 时不改写预算相关参数；Anthropic 模型自身的输出上限钳制独立生效。prepaid 同时保留钱包余额限制，月额度不会自动充值。启用额度后更换币种、时区需先停用默认规则、清除个人覆盖并处理在途请求。

额度覆盖网关 Chat、Responses、Messages、Embeddings 和 Images 的既有计费路径。通用 HTTP 代理没有模型计费接入。崩溃请求的持久预占保留以防并发超用，下月不受上月预占影响。

## 计费记录与日志留存

系统设置里的“日志与内容留存天数”（最少 30 天）只清理访问记录明细、内容留存、内容审计和工具调用审计；安全事件及其关联记录、告警、操作审计、审计完整性记录不清理。计费记录（用量事实、账本流水）长期保留，不受日志留存天数影响。

## 币种与统计

支持人民币和美元，不换汇。模型报价、额度、钱包保存实际币种；币种不一致的额度调用会拒绝。用量分析按币种筛选，不直接加总不同币种。财务结算自行决定汇率。

金额和倍率显示、编辑两位小数；未修改的历史精确金额不被截断。低于 0.01 的非零图片/调用单价可用每千单位配置。CSV 输出两位小数，Excel 显示两位并保留精确金额。

进入“计费驾驶舱 → Token 用量”查看 Prompt 输入、缓存命中、缓存写入、输出和推理用量，以及图片、工具计数。图像 Token 细分随账单保存；上游未提供的细分不能凭空构造。对账表按固定列宽横向滚动，提供左右查看和详情按钮，金额不折行，完整编号可查看、复制。

## 上游成本

在“上游渠道成本”按渠道/模型录入真实采购价，包含 Token、缓存、图片、推理、调用和工具费用。成本在当次账单落库时固定，改价不回写历史。未录入或币种不同留空，不当作零成本、不換汇。Excel 上游成本列使用当次固定成本。

## 自定义替换和还原

在“防护策略 → 策略中心 → 场景策略 → 敏感数据外发”按类型设置替换模板、响应还原开关，也可覆盖单条规则。请求内占位符映射只还原本次实际替换的原文，不写入审计和检测缓存。响应先完成安全检测及脱敏审计，再按设置还原给调用者。

支持网关文本 API 与反向代理的受支持文本路径，包括流式文本。通用正向代理为保持协议和签名，只告警、放行原文；附件和图片像素不进行可逆替换。自定义规则应避免过宽正则。

## 验证与发布

计费数据库回归使用一次性 PostgreSQL/Redis；页面交互和短窗口布局使用隔离 mock 页面测试，真实部署后再验证只读 API、静态资源与运行状态。mock 截图不冒充真实业务数据。

虚拟机更新使用受控 preserve-tier1 发布并固化启动链。本轮不需要新增数据库迁移；不修改 VERSION、模型权重、安全执行模式和审计设置。全量 Web lint 的既有 ModelProbeDialog/AlertInbox 七项 React 警告单独记录，修改文件检查必须通过。

Anthropic 输出上限、模型名匹配和环境变量配置见 [Anthropic 输出上限运维说明](operations/gateway-anthropic-output-limits.md)。
