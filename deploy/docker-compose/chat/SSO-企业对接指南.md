# JJDGuard 企业 SSO 对接指南

本文面向企业 IT 与安全管理员。企业身份源的新增、测试、启用、停用和漂移修复，全部在 JJDGuard 管理后台完成；不需要也不应访问任何内部身份管理组件。

## 1. 对接边界

- JJDGuard 管理后台继续使用本地管理员账号登录，不切换为企业 SSO。
- 员工从“企业 AI 门户”进入，通过企业 SSO 登录。
- JJDGuard 目前接入标准 OIDC Discovery。企业 AD/LDAP 应先由现有企业身份平台提供 OIDC；不要把目录管理口直接暴露给 JJDGuard。
- 上线前必须保留至少一个状态正常、可使用密码登录的本地管理员，作为应急入口。

## 2. 企业身份平台准备

请向企业身份平台管理员获取：

| 参数 | 说明 |
|---|---|
| Discovery 地址 | 以 `/.well-known/openid-configuration` 结尾的 HTTPS 地址 |
| Client ID | 为 JJDGuard 员工门户创建的 OIDC 应用标识 |
| Client Secret | 该 OIDC 应用的密钥，只在 JJDGuard 页面录入 |
| Scopes | 建议 `openid profile email`，按需增加企业分组 scope |
| 声明 | 至少包含稳定 `sub`；建议提供 `email`、`name`、`department`、`groups` |

不要先手工填写回调地址。JJDGuard 会在安装、升级或恢复时自动生成并持久化公开 SSO 地址，页面显示的完整回调地址才是登记依据。
客户未提供正式域名时，系统默认复用部署主机 Web HTTPS 入口的 IP 与端口生成回调，适合私有部署、联调和测试。
正式客户交付建议后续配置稳定 DNS 与 HTTPS；这会改变回调基址，变更后需按页面当前值重新登记企业身份平台。

## 3. 在 JJDGuard 中配置

1. 使用本地管理员账号登录 JJDGuard 管理后台。
2. 打开“身份与访问” → “登录与单点登录”。
3. 在“回调地址”处复制完整地址，登记到企业身份平台的允许回调列表。
4. 填写显示名称、Discovery 地址、Client ID、Client Secret 和 Scopes。
5. 点击“保存草稿”。
6. 点击“测试连接”；只有测试通过的草稿才能启用。
7. 点击“确认启用”，等待页面状态变为“已启用”。

回调地址的路径形态类似：

```text
https://guard.company.example/sso/realms/jjdguard/broker/enterprise/endpoint
https://10.20.30.40/sso/realms/jjdguard/broker/enterprise/endpoint
```

域名、协议和端口必须复制当前页面的真实值，不能照抄示例。
如果企业 IdP 拒绝 IP 或 HTTP 回调，这是 IdP 的安全策略限制；请由客户提供域名/证书，系统不会自动申请公网域名或证书。

## 4. 验收员工登录

1. 使用无管理员会话的浏览器访问企业 AI 门户。
2. 点击“企业 SSO 登录”。
3. 在企业身份平台完成认证与授权。
4. 确认浏览器回到门户，员工姓名、邮箱与部门信息正确。
5. 在 JJDGuard 审计与用量页面确认该请求按员工和部门归因。

管理员后台的本地密码登录应同时复测，不能因员工 SSO 异常而失效。

## 5. 配置状态与修复

| 页面状态 | 处理方式 |
|---|---|
| 部署尚未配置公开 SSO 地址 | 只有自动解析失败才会出现；先检查部署主机地址、端口和权限，不要手工填写内部容器地址 |
| 测试失败 | 核对 Discovery 地址、Client ID/Secret、证书链和网络可达性 |
| 发布失败 | 原有已启用配置不会被切换；修正草稿后重新测试、启用 |
| 配置需修复 | 核对页面保存内容后点击“按当前配置修复”，并在确认框再次确认 |
| 身份服务暂不可用 | 员工 SSO 暂不可用，本地管理员登录不受影响；联系平台运维恢复内部服务 |
| 回调地址不匹配 | 删除企业身份平台中的旧回调，重新复制 JJDGuard 页面当前值 |

## 6. 上线安全要求

- 无正式域名时的 IP/HTTP 地址可用于私有部署和测试，但应限制网络暴露范围，并接受企业 IdP 可能拒绝该回调。
- 正式客户交付必须使用稳定 DNS 与 HTTPS，避免 IP 变化、登录重定向风险和企业策略不兼容。
- Client Secret 只在 JJDGuard 页面录入，不发到群聊、工单正文或截图中。
- 企业身份平台应限制精确回调地址，不使用宽泛通配符。
- 启用后至少完成一次成功登录、一次拒绝登录和一次本地管理员应急登录。
- 定期复核企业身份平台应用密钥、员工离职禁用和部门/分组声明。

内部恢复、服务账号和运行组件操作不属于客户配置流程，由平台运维按《SSO-内部恢复手册》执行。
